# Vibe Surgeon 0.2.1 — public preview

Know what to review after AI edits your repository.

This is an early heuristic analysis tool, not a security certification or an
application test runner. The score is not a probability of correctness.

## In this preview

- A reproducible synthetic demo: one changed file, three potentially affected files.
- Fixed fail-open Git comparison: invalid refs, missing history and non-repositories
  now fail explicitly instead of producing an empty diff.
- NUL-delimited Git filenames, explicit tracked-file scope, subdirectory guard check.
- Working source-install instructions, English/Russian introductions and feedback form.
- Regression tests for the Git failure paths.

## Run from source

```bash
git clone --branch v0.2.1 https://github.com/adilusrr-gif/vibe-surgeon.git
cd vibe-surgeon
npm ci --ignore-scripts
npm test
npm run demo
node bin/vibe-surgeon.mjs all /path/to/your/repository
```

Or download the attached `.tgz`, verify it against `SHA256SUMS`, and install it
with `npm install -g ./vibe-surgeon-0.2.1.tgz --ignore-scripts`.
The tarball is a GitHub release asset; this workflow does not publish to npm.

The attached `report.html`, `evidence.json` and `transcript.txt` are generated from
a deliberately small synthetic fixture, not a customer repository or benchmark.
The demo's exit 2 is expected: the guard recommends review rather than declaring
the change broken. Run your own tests and review the diff before merging.

## Known limits

Local JS/TS import paths are recognized heuristically. Aliases, runtime wiring,
Python imports and semantic test coverage are incomplete. Untracked files are
not included in the Git guard. A present `.env` is not proof it was committed.
Use only trusted local MCP clients; MCP is not a filesystem sandbox.
